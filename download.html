How to Open in VS Code

1 Unzip the file

Right-click the downloaded repo.zip file and choose "Extract All..." (Windows) or double-click it (macOS).

2 Open in Visual Studio Code

Open VS Code, click File > Open Folder..., and select the unzipped folder.

3 Preview locally with Live Server

In VS Code, install the Live Server extension, right-click index.html, and select "Open with Live Server".
